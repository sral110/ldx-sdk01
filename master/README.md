# LDX Master

این پوشه منبع حقیقت محصول و مرز میان «منطق آموزشی» و «پیاده‌سازی» است.

## فایل‌ها

- **MASTER-v0.1.md** — سند مادر انسانی: مسئله، ضرورت، مخاطب، دامنه، Workflow، AI، منابع، اصول، ممیزی و معیار پذیرش.
- **VARIABILITY-MAP.md** — نقشه آنچه باید ثابت، قابل تنظیم، Plugin یا App-specific باشد.
- **master.config.v0.1.json** — نمونه پیکربندی ماشین‌خوان.
- **master.schema.v0.1.json** — Schema اولیه برای اعتبارسنجی Master Config.

## قاعده توسعه

هر تغییر مهم ابتدا در Master مشخص می‌شود، سپس قرارداد SDK و تست آن نوشته می‌شود، و در آخر UI آن را مصرف می‌کند.

```
Master → SDK Contract → Tests → App/UI
```
